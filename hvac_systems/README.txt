HVAC Systems Image Folder
=========================

Drop one image per HVAC system into this folder.

Naming convention:
  - Use the system name as the filename
  - Supported formats: .png, .jpg, .jpeg, .webp
  - Examples:
      Carrier 2-Ton.png
      Trane XR15.jpg
      Lennox XC21.png
      Goodman GSX16.jpg

The filename (without extension) becomes the dropdown option in the form.
Keep names clean — they show up exactly as typed in the UI.
